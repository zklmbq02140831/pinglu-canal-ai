# 答辩Q&A预案

> 规则：每条≤3行，条目末尾注明来源日期；答辩前一周专刷本文件。

**Q1：不同库计算的指数为何有微小差异？**（Day12）
A：G_Local输入经numpy(ddof=0)与pandas(ddof=1)两种标准化，自由度约定不同，
z值差异仅8e-03量级（第三位小数），远离±1.96阈值，不改变任何显著性判定。

**Q2：冷点格composite高于全域均值0.107，为何还是冷点？**（Day12）
A：Gi*比较的是邻域窗口均值与全域随机期望——条带自身值不低，但Queen邻域
含大量运河沿线未开发格，窗口均值被拉到期望之下，故z显著为负
（13格z<-1.96，最冷-3.84，最弱-2.10）。

**Q3：术语规范**（Day12）
A：统一表述为"被高值城区包围的贴河低值条带（Gi*显著冷点）"；
避免使用"LH相对低值洞"（LISA四象限术语，Gi*不输出该标签）。
