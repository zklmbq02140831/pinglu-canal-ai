## P6 · 决策支持章：事实锚定 + 幻觉治理三层根因链

### 页面标题
**决策支持：事实锚定徽章 + 同题前后对照幻觉治理**

### 要点（带出处）
1. **事实锚定机制**：IndexAgent 答案前置 `[事实锚定·本地快照]` 标记 → 前端渲染绿色徽章（`frontend/app.py:726-731`）；事实表 `canal_facts.py` 每条均含 source 字段
2. **sources 相关度展示**：PolicyAgent 答案下方渲染来源卡片，含 title / score / snippet，阈值 0.45（`frontend/app.py:812-829`）
3. **幻觉治理 - 三层根因链**（论文实验章节核心案例）：
   - **第一层 top_k 截断**：原 `DEFAULT_TOP_K=5` 过小，导致 #23 chunk（相似度 0.4933）等高相关片段被截断
   - **第二层 LLM 跳过工具编造**：LangGraph `create_react_agent` 在弱约束下跳过 `search_policy` 工具，**虚构文档**《通航标准》《可行性研究报告》（正向幻觉实锤——这两份文档不在 13 份语料中）
   - **第三层 prompt 弱约束**：原 system prompt 未强制工具调用，未规定四层漏斗回答规则
4. **同题前后对照**（commit `00a1693` 修复前后）：
   - **修复前**：问"平陆运河规划通航船舶吨位是多少？" → 答"未涉及该问题"
   - **修复后**：问同题 → 答"5000 吨级"+ 出处 08 号《航海保障体系三年行动计划》
5. **修复方案**：`DEFAULT_TOP_K=25` + `tool_search_policy` 默认 `top_k=25, min_score=0.45` + BOOST_KWS 关键词置顶 + 四层漏斗 system prompt + 拒答话术"无法在 13 份平陆运河相关政策文档中检索到该问题的对应内容"
