# 架构铁律(长期生效)

> 生效日期:Day14晚(2026-09-29)· 首次成文化:额度战时管理复盘
> 性质:**不可豁免**。不因额度刷新、换key、换账号而解禁;违反即架构回退。

## 铁律1:Agent运行时零触网

- Agent 工具(Index / Analysis / Narrator 及一切运行时服务)只读本地缓存
  `data/raw/poi_cache/` 与 `data/processed/`,**运行时禁止调用高德API**。
- 违反场景示例:用户点击地图→后端现场抓POI;筛选联动→实时查高德。一律禁止。

## 铁律2:物理隔离,不是逻辑禁止

- 运行时代码不集成高德 key / URL / SDK——**物理够不着**,而非"逻辑上不允许"。
- 验收标准:运行时镜像/依赖里 grep 不到 `restapi.amap.com` 与 `AMAP_KEY` 的引用。

## 铁律3:数据快照版本化

- 数据快照版本 **v2026-09**。
- 后续任何数据更新走固定管线:**离线批处理 → 落盘 data/processed → 版本号+1**;
  运行时永不触网。
- 运行时声明所依赖的快照版本(如 dataset_card / data_dictionary 顶部标注),
  版本不符视为部署错误。

## 铁律4:抓取层工程规范(离线批处理适用)

1. **错误码分级**(高德):
   - QPS族 {10004,10014,10015,10019,10020,10021} → 指数退避重试(1/2/4/8/16s,至多5次),耗尽=未完成;
   - 配额族 {10003,10044,10029} → 立即停整任务,当前(类目,子格)不缓存,绝不把残缺序列当完整落盘;
   - 10006=完整空集;网络异常同退避重试;其余 status!=1 → 未完成不入缓存。
2. **checkpoint**:每序列即抓即存;每(组,类目)完成即写 done manifest;断点续跑无损。
3. **done门控**:分析/比值只纳入 manifest 有 done 标记的(组,类目);无标记=不进口径,显式列出。
4. **截断防御**:翻页上限(实测约200/序列)→ ≥190 即细分递归;细分只允许在既定覆盖内
   (并集细分不得越出格覆盖);完成后做下限校验(已知重叠区计数必须被达到)。
5. **预算硬顶**:任何批量抓取必须先声明请求预算(硬顶常量),触顶即停+报告。

## 背景

Day14 全量抓取约4400次请求耗尽月度减免额度80%+;凹槽POI品类验证在战时额度下
收尾(见 decisions.md Day14晚)。教训:运行时触网不可控、不可复现、不可预算;
数据只有快照化、版本化、离线化才可答辩。
